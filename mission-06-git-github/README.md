## Git workflow

- git status shows changed, staged, and untracked files.
- git add selects changes for the next commit.
- git commit records staged changes in local history.
- git log --oneline shows recent commits.
- A commit is not automatically uploaded; pushing publishes commits to a remote repository.

A branch is a separate line of project history. A Pull Request proposes changes from a branch for review before merging. Reviewers can inspect the changes and discuss them before they join the target branch.

## Git command glossary

- git init starts tracking a folder as a Git repository.
- git status inspects staged, unstaged, and untracked changes.
- git add <file> stages a chosen file.
- git commit -m "message" saves staged changes in local history.
- git log --oneline shows compact commit history.
- git branch lists branches; git branch <name> creates one.
- git switch <name> moves to another branch.
- git push -u origin <name> publishes a local branch and sets its upstream.
- git pull retrieves and integrates changes from a remote branch.
