## Compiler and interpreter

A compiler translates source code before execution, often producing an executable or intermediate form. An interpreter runs instructions through a runtime as the program executes. C is commonly compiled with GCC; Python is commonly run through CPython. Implementations may combine techniques.

| Compiler | Interpreter |
|---|---|
| Translation commonly happens before the program runs. | Instructions are handled during execution. |
| Often produces an executable or intermediate form. | Runs through a runtime; a standalone executable is not always created. |
| Can run efficiently after compilation on a compatible system. | Makes it quick to try and change code. |
